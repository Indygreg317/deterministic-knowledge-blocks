# Verification Documentation

## Purpose

This directory is the documentation entry point for verification evidence in the deterministic Knowledge Blocks repository.

The repository treats verification as a reviewable evidence path, not a trust claim. A reader should be able to locate the relevant artifacts, inspect the schemas, run the verifier, review expected outcomes, and distinguish declarations from independently checkable evidence.

## Verification Boundary

Verification artifacts should show what was checked, what evidence was available, what rule was applied, what result was recomputed, and what remains outside the verifier boundary.

A governance artifact may declare scope, policy, authority, or continuity. Verification evidence should make those declarations inspectable, replayable, or clearly unsupported.
