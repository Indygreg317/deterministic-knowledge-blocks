# Contributing

## Purpose

This repository explores deterministic evaluation architectures for uncertain or probabilistic systems.

Contributions should improve:

- clarity
- auditability
- replayability
- deterministic evaluation behavior
- governance transparency

## Contribution Areas

Examples of useful contributions:

- schema improvements
- evaluator examples
- replay verification patterns
- governance documentation
- execution receipt enhancements
- validation tooling
- additional use cases

## Design Principles

Contributions should preserve the core architectural principle:

> Inputs may remain uncertain.
> Evaluation behavior should remain explicit and auditable.

## Pull Requests

Please:

- describe the architectural purpose of changes
- explain governance implications where relevant
- preserve backward compatibility where practical
- avoid introducing hidden evaluation behavior

## Experimental Status

This repository is experimental and should not be treated as production-ready infrastructure without expert review and validation.
